# 🎙️ Voice AI Assistant

A fully free voice-to-voice AI assistant built with:
- 🎧 **Whisper** — Speech to Text (OpenAI, runs locally)
- 🧠 **LLaMA 3.3 70B** — LLM via Groq API
- 🔊 **gTTS** — Text to Speech (Google)
- 🖥️ **Gradio** — Frontend UI
